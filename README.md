# BLAST Optimisation: Система автоматизации сравнения генетических последовательностей

Программный комплекс на Python для автоматизации сравнительного анализа генетических последовательностей с использованием локальной версии BLAST+. 

Проект разработан в рамках курсовой работы и предназначен для замены ручного анализа через веб-интерфейс NCBI. Система позволяет проводить массовые сравнения последовательностей офлайн, что повышает скорость работы и обеспечивает конфиденциальность данных.

## 📌 Основные возможности

* **Автоматизация BLAST+:** Скрипт самостоятельно подготавливает входные файлы, создает локальную базу данных (`makeblastdb`) и запускает поиск (`blastn`).
* **Гибкость входных данных:** Поддерживает загрузку последовательностей как из FASTA-файлов, так и в виде "сырых" строк.
* **Продвинутый парсинг:** Обработка результатов BLAST (TSV/XML), фильтрация ошибок и расчет сводных метрик:
  * Max Score / Total Score
  * Query Cover (покрытие запроса)
  * Percent Identity (процент идентичности)
  * Acc. Len (длина последовательности-субъекта)
* **Экспорт результатов:** Формирование итоговых сводных таблиц.

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.10+
* **Библиотеки:** `biopython` (для работы с FASTA и парсинга XML), `pandas` (для обработки и агрегации табличных данных).
* **Внешние утилиты:** NCBI BLAST+ (утилиты `blastn`, `makeblastdb`).

## ⚙️ Установка и требования

1. **Установите локальный BLAST+**
   Скачайте и установите пакет BLAST+ с [официального сайта NCBI](https://ftp.ncbi.nlm.nih.gov/blast/executables/blast+/LATEST/). 
   *Важно: убедитесь, что путь к папке `bin` (например, `C:\blast\bin`) добавлен в системную переменную `PATH`.*
   Проверить установку можно командой в терминале: `blastn -version`

2. **Установите Python-зависимости**
   Клонируйте репозиторий и установите необходимые библиотеки:

       pip install biopython pandas

## 🚀 Использование

Запуск программы осуществляется через командную строку. 

**Пример запуска:**

    python main.py --query gene.fasta --subjects genome.fasta --out results_dir

**Аргументы командной строки:**
* `--query`: Путь к файлу с последовательностью-запросом (или сама строка).
* `--subjects`: Путь к файлу(ам) с последовательностями-субъектами (или строки).
* `--out`: Директория для сохранения результатов.

**Результат работы:**
Программа создаст папку с результатами, в которой будет находиться сводная таблица с метриками выравнивания, готовая для дальнейшего анализа.

## 📂 Структура проекта

* `main.py` — главный исполняемый файл (точка входа).
* `blast_utils.py` — вспомогательные функции для работы с BLAST+ и парсинга.
* `blast_processing.py` — логика подготовки данных и вычисления сводных метрик (Score, Cover, Identity).
* `blast_io.py` — модуль ввода-вывода.
